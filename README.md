 OfficeFlow Free

**All-in-One Free GST & Productivity Tools for Indian Small Businesses (2026)**

A simple, powerful, and completely free web-based office toolkit designed for freelancers, solopreneurs, and small businesses.

## ✨ Features

### Core Tools
- **GST Invoice Generator** (Fully Compliant)
  - Automatic CGST + SGST / IGST calculation based on Place of Supply
  - Support for all Indian states & union territories
  - Real-time tax breakdown + Grand Total in words
  - Professional PDF download with watermark
  - AI-powered item suggestion from plain English description

- **AI Document Writer**
  - Generate professional proposals, emails, reports, and letters
  - Supports multiple AI providers

- **Smart Task Board**
  - Simple Kanban-style task management
  - AI task prioritization

- **Social & Promo Content Creator**
  - Generate ready-to-post captions and hashtags

### AI Integration (Multi-Provider Support)
Choose your preferred AI model:
- **Grok** (xAI)
- **Gemini** (Google)
- **Claude** (Anthropic)
- **Perplexity**

Just add your API key in Settings — works with any of them.

## 🚀 Quick Start

1. Download or clone the repository
2. Open `officeflow-free.html` in any modern browser (Chrome, Edge, Firefox)
3. (Optional) Go to **AI Settings** tab and add your preferred AI API key for smarter features
4. Start creating GST invoices instantly!

No installation or server required.
